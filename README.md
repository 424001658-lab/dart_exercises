## Scenario Description
This program calculates the final bill for a retail store purchase. It tracks the customer's name, item quantity, unit price, and membership status to compute total cost, calculate free item perks using integer division and modulo operators, and check if the total qualifies for a high-value discount.

## Variables & Data Types Used
- `int`: `quantity` (Number of items bought)
- `double`: `unitPrice` (Price per item)
- `String`: `studentName` (Customer name)
- `bool`: `isMember` (Membership status)
